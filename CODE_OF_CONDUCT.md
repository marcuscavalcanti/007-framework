# Code of conduct

007 Framework adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and assume good faith. Criticise claims, methods and code, not people. A disagreement about evidence
is settled with evidence. Harassment, personal attacks and publishing someone's private information are not accepted, in
issues, pull requests or any project space.

Report a problem privately to the maintainer through
[GitHub private reporting](https://github.com/marcuscavalcanti/007-framework/security/advisories/new) and mark it as a
conduct report. Reports are kept confidential. The maintainer may warn, remove content, or block someone from the project,
following the Covenant's enforcement guidelines.
