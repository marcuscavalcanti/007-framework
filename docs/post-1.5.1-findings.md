# Post-1.5.1 findings

Owner: Codex. Status: working record, not a subsequent-release promise.
Current scope: backward-compatible dashboard corrections on the existing flow.
No new dependencies, receipt schema, database or scheduler.

## Observed

- An escape declaration can immediately be displayed as mature D7 survival.
  1.5.1 must label the declaration, not invent independent follow-up evidence.
- Accepted plus blocked receipts use different first-pass denominators by route
  and aggregate. Keep accepted follow-up denominators aligned; failed attempts
  still contribute to cost and time.
- Provisional accounting, open attempts and causal identity gaps need explicit
  adjacent labels, not only a diagnostics footnote.
- Authority provenance does not establish controller-observed acceptance.

## Deferred candidates, not proved benefits

- Prospective, candidate-bound D7 follow-up is a new capture capability, not a
  dashboard label fix. Require an executable contract before claiming durability.
- Legacy route recommendations still consume declared follow-up. Qualification
  of stronger evidence must cover the selector as well as the presentation.
- Cross-project cases require verified historical defects and sanitized oracles.
  Deterministic synthetic cells do not become private-project replays by renaming.

## Progress

- v1.5.0 installed independently; previous local links retained for rollback.
- Base full suite: 148 tests passed outside the sandbox. Sandbox loopback denial
  is an environment failure, not a product regression.
- Dashboard regressions written before implementation. Integrated and full-history
  clean-source checks each passed 155 tests; renderer passed 5 checks. Mobile
  and desktop were observed, and the temporary viewport override was reset.
- The admission experiment now has 36 valid cells on two sanitized cases, three
  repetitions per condition/arm, zero invalid and zero source drift. Earlier
  cost/telemetry-contract mistakes in the synthetic executor remain as two
  inconclusive records; no repeated result is counted as a new independent case.
- Review-context, manifest and supported-version CI remain release
  work, not new product capabilities. Do not add capture infrastructure to make
  the dashboard look more measured than its receipts.
- Internal review exposed mismatched ledger/aggregate acceptance classification
  for empty checks and missing per-route cost provenance. Both now have
  RED→GREEN regressions, including preservation of observed failed checks and
  mixed-source project aggregation. No external approval is inferred.
- 1.5.1 publication remains gated on clean-source/UI proof, exact-candidate CI,
  frozen bytes and a separately authorized external review/publication.
